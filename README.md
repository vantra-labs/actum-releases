# Actum — установщики

Actum — программа для Windows, которая готовит исполнительную документацию по объекту: акты, журналы и том ИД.

**[Скачать последнюю версию — Actum-Setup.exe](https://github.com/vantra-labs/actum-releases/releases/latest/download/Actum-Setup.exe)**

- Установка в один клик, без прав администратора.
- Повторная установка поверх обновляет программу: объекты и настройки сохраняются.
- Программа обновляется сама, если есть интернет.

При первом запуске установщика Windows может показать окно «Windows защитил ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

В этом репозитории лежат только установщики. Код программы — в отдельном закрытом репозитории.
